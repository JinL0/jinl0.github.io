A digital twin is a live, physically accurate virtual copy of a factory, robot, data center or planet, kept in sync with sensor data so you can test changes before you make them. The loop

How a digital twin works

Most industrial twins follow the same four-step loop. The products below plug into one or more steps.

Describe

Combine CAD, BIM, PLM and sensor layouts into one shared 3D scene description (OpenUSD) that every tool can read and edit.

Simulate

Run physics, sensors and robots in that scene: lighting, cameras, lidar, fluid and thermal behavior, robot motion.

Predict & train

Use AI models to generate synthetic data, train robot policies, and replace slow solvers with fast surrogate models.

Operate

Stream live data into the twin, test "what-if" changes, and push optimized plans back to the real factory or fleet.
